Tic Tac Toe 🎮
A clean, responsive, and classic Tic Tac Toe game built using vanilla HTML5, CSS3, and JavaScript. Designed for two players sharing the same device for local, offline head-to-head matches!

✨ Features
2-Player Local Multiplayer: Pass-and-play style game designed for two friends playing on the same screen (Player X vs. Player O).

Fully Responsive: Looks and plays great on desktop computers, tablets, and mobile phones.

Instant Win & Draw Detection: Automatically identifies winning combinations (horizontal, vertical, diagonal) or detects a tie.

Clean & Modern UI: Simple, distraction-free aesthetic with intuitive turn indicators and smooth hover effects.

Quick Restart: Reset the board instantly for a rematch without needing to refresh the browser.

🛠️ Technologies Used
HTML5: Game board structure and layout

CSS3: Styling, grid layout, animations, and responsive design

Vanilla JavaScript (ES6+): Game logic, state management, and DOM manipulation

🚀 Getting Started
Since this project is built with vanilla web technologies, you don't need to install any node modules or run complex build tools.

Prerequisites
All you need is a modern web browser (Chrome, Firefox, Safari, Edge, etc.).

Installation & Running Locally
Clone or Download this repository to your local machine:

Bash
git clone https://github.com/your-username/tic-tac-toe.git
Navigate into the project folder.

Open the index.html file directly in your web browser (double-click the file, or drag and drop it into an open browser window).

🕹️ How to Play
Player X always goes first.

Players take turns clicking on any empty cell on the 3x3 grid.

Your symbol (X or O) will appear in the selected box.

The first player to align 3 of their symbols in a row (horizontally, vertically, or diagonally) wins the game!

If all 9 cells fill up and no player has 3 in a row, the game ends in a draw.

Click the "Restart" or "Play Again" button to start a fresh round.
